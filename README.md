# 📸 Insta Arena
## 📝 Sobre o Projeto
O **Insta Arena** é um site desenvolvido com o objetivo de simular uma rede social de compartilhamento de fotos e interações, inspirada em plataformas populares como o Instagram.  
A aplicação permite que os usuários visualizem postagens, curtam fotos, comentem e explorem perfis — tudo dentro de uma interface moderna, responsiva e intuitiva.
O projeto foi criado com foco em praticar e aplicar conceitos de **desenvolvimento front-end**, aprimorando o uso de **HTML5**, **CSS3** e **JavaScript**.

---
## 🚀 Tecnologias Utilizadas
 
- **HTML5**: Estruturação da página e marcação semântica.  
- **CSS3**: Estilização e design responsivo da interface.  
- **JavaScript**: Funcionalidades dinâmicas e interatividade.  
- **IDEs**: Visual Studio Code (VS Code) e Spring Tool Suite (STS).
- **Spring Boot**: Framework utilizado para a criação da aplicação e integração com o banco de dados.  
- **MySQL**: Banco de dados utilizado para armazenamento das informações do usuário.
